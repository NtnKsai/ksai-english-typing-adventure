# Ksai English Typing Adventure · V2.0

เว็บแอปฝึกพิมพ์ภาษาอังกฤษสำหรับนักเรียนประถม ออกแบบให้เริ่มเรียนตามลำดับ **บทที่ 1–6** พร้อมระบบฝึกพิมพ์ วัดผล ติดตามพัฒนาการ และเครื่องมือสำหรับครู

**ผู้พัฒนา:** NtnKsai  
**หน่วยงาน:** โรงเรียนวัดแคทราย (บุญประชาสรรค์)

## เปิดใช้งาน

1. ดาวน์โหลดและแตกไฟล์ `english-typing-adventure.zip`
2. เปิดไฟล์ `index.html` ด้วย Google Chrome, Microsoft Edge หรือ Firefox รุ่นปัจจุบัน
3. สร้างโปรไฟล์ด้วยชื่อเล่นและห้องเรียน (ห้องเรียนไม่จำเป็นต้องกรอก)
4. เริ่มจากบทที่ 1 เลือกหัวข้อและระดับ Easy หรือ Medium แล้วกดเริ่มฝึก

แอปเป็นเว็บแบบ Static ไม่ต้องติดตั้งโปรแกรมหรือเซิร์ฟเวอร์เพื่อทดลองใช้

## คุณสมบัติ V2.0

- ใช้ชื่อแอป **Ksai English Typing Adventure** พร้อมเครดิตผู้พัฒนา
- เปลี่ยนจากระดับชั้นเป็น **บทที่ 1–6** ตามลำดับเนื้อหา
- เริ่มจากบทที่ 1 และปลดล็อกบทถัดไปเมื่อ Accuracy ตั้งแต่ 70% ขึ้นไป
- เลือกย้อนกลับไปฝึกบทที่ปลดล็อกแล้วได้เอง
- ขยายตัวอักษรโจทย์ภาษาอังกฤษให้ใหญ่และชัดขึ้น
- เลือกโหมดฝึก 1, 3, 5 นาที หรือไม่จำกัดเวลา
- วัด WPM, Accuracy, จำนวนตัวอักษรถูก/ผิด และคะแนน
- แสดง Dashboard พัฒนาการ กราฟจริง ประวัติ และรางวัลของผู้เรียน
- Teacher Dashboard แสดงรายชื่อนักเรียน ห้องเรียน ตารางคะแนน การฝึกล่าสุด และรายงานรายบุคคลสำหรับพิมพ์
- ส่งออกรายงานรวมเป็น CSV
- สำรองข้อมูลผู้เรียนเป็น JSON
- เชื่อม Google Sheets ได้ผ่าน Apps Script (ต้องตั้งค่า URL และ Deploy เอง)
- รองรับคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ

## วิธีปลดล็อกบทเรียน

| บท | เนื้อหาหลัก |
|---|---|
| บทที่ 1 | ตัวอักษร A–Z และคำสั้น ๆ |
| บทที่ 2 | คำศัพท์พื้นฐาน |
| บทที่ 3 | คำศัพท์และวลีสั้น ๆ |
| บทที่ 4 | ประโยคภาษาอังกฤษง่าย ๆ |
| บทที่ 5 | ประโยคในชีวิตประจำวัน |
| บทที่ 6 | ข้อความสั้น ๆ และความคล่องแคล่ว |

ทำแบบฝึกในบทปัจจุบันให้สำเร็จอย่างน้อย 3 ข้อ และมี Accuracy อย่างน้อย 70% ระบบจึงจะบันทึกว่าผ่านบทนั้นและปลดล็อกบทถัดไปให้อัตโนมัติ ผู้เรียนเลือกบทที่ปลดล็อกแล้วได้จากแถบเส้นทางบทเรียน

## การจัดเก็บข้อมูล

- โดยปกติข้อมูลจะบันทึกใน Local Storage ของเบราว์เซอร์และอุปกรณ์นั้น
- สามารถสร้างผู้ฝึกหลายโปรไฟล์บนอุปกรณ์เดียวกัน และระบุห้องเรียนเพื่อกรองใน Teacher Dashboard
- ข้อมูลไม่ถูกส่งออกไปที่อื่นโดยอัตโนมัติ
- ใช้ปุ่มสำรองข้อมูล JSON เป็นระยะ โดยเฉพาะก่อนย้ายเครื่องหรือล้างข้อมูลเบราว์เซอร์
- ประวัติจาก V1 จะถูกรักษาไว้โดยระบุว่าเป็น “ข้อมูลรุ่นเดิม” และโปรไฟล์จะเริ่มหลักสูตรใหม่ที่บทที่ 1 เพราะข้อมูล V1 เดิมเก็บระดับชั้น ไม่ใช่บทเรียน

## Google Sheets Integration

ดูขั้นตอนเต็มใน `DEPLOY_GUIDE.md` และใช้ไฟล์ `GoogleAppsScript.gs` เป็นตัวรับข้อมูล โดยระบบจะรวมข้อมูลนักเรียนและประวัติจากหลายอุปกรณ์ตามรหัสรายการที่ไม่ซ้ำกัน

> หมายเหตุ: ปุ่มซิงก์ในเว็บส่งข้อมูลไปยัง Google Apps Script แบบ no-cors เพื่อรองรับการเรียกข้ามโดเมน จึงไม่สามารถยืนยันผลตอบกลับจากเบราว์เซอร์ได้ ต้องเปิด Google Sheets เพื่อตรวจว่าข้อมูลเข้าครบหรือไม่

## ข้อจำกัดและข้อควรระวัง

- Teacher Dashboard ในเว็บแสดงข้อมูลที่อยู่ในเบราว์เซอร์/อุปกรณ์ปัจจุบัน ส่วนข้อมูลจากหลายอุปกรณ์จะถูกรวบรวมใน Google Sheets หลังตั้งค่าการเชื่อมต่อ
- Teacher Dashboard ยังไม่มีระบบบัญชีครูหรือ PIN จึงไม่ควรเปิดเผยอุปกรณ์ที่มีข้อมูลนักเรียนให้ผู้อื่นใช้ร่วมกันโดยไม่มีการดูแล
- หลีกเลี่ยงการบันทึกนามสกุล เลขประจำตัว ที่อยู่ หรือข้อมูลส่วนบุคคลที่ละเอียดอ่อน ใช้เพียงชื่อเล่นและห้องเรียน
- การ Deploy Google Apps Script เป็น Web App ต้องพิจารณาสิทธิ์ผู้เข้าถึง และควรตั้ง `SYNC_TOKEN` ตามคู่มือ
